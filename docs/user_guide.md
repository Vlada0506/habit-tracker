# Руководство пользователя

## Добавление привычки

Нажмите "Добавить привычку".

Заполните:

- Название
- Описание
- Цель в день

Нажмите "Создать".

## Отметка выполнения

Нажмите кнопку "Выполнено".

Каждое нажатие добавляет одно выполнение за текущий день.

## Поиск

Введите название привычки в поле поиска.

## История

Нажмите "История" для просмотра статистики за 7 дней.
